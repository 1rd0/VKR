# Демонстрационный документ

Этот файл нужен для первого запуска baseline RAG.

Правила работы с внутренними документами:

1. Актуальной считается последняя утвержденная версия документа.
2. Изменения в регламент вносятся приказом руководителя.
3. Если сотрудник использует устаревшую инструкцию, приоритет имеет новая редакция.
4. Все PDF и HTML документы должны храниться в централизованной базе знаний.

Порядок ответов чат-бота:

- бот должен опираться на найденные фрагменты документов;
- если информации недостаточно, бот обязан сообщить об этом;
- бот не должен придумывать факты, которых нет в базе.
